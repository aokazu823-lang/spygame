# SPY GAME 司会室（iPad / GitHub Pages）

2026年11月22日の家族スパイゲームを進行するための、HTML・CSS・JavaScript製の司会支援Webアプリです。

## 対応競技

1. **色の記憶ゲーム**：15枚、A3台紙、20秒暗記、5人に3枚ずつ配布。正解数をタップで記録。色の配置は子どもが自由に作り、正解写真はスマホ等で1回だけ撮ります。**アプリには撮影機能を設けていません**。
2. **順手・逆手 絵しりとり**：大人5人の順番と「順手3枚・逆手2枚」を抽選し、各30秒のタイマーで進行。5枚の絵は紙で保管。4つのつながりを採点。
3. **文字数しばりしりとり**：トランプ2〜6、赤=カタカナ語、黒=それ以外の日本語。大人5人が2巡、計10手番。**全員共通の制限時間**で挑戦。相談なし。回答は紙で記録。実物のカードとアプリ内抽選を選択可能。

競技の成功ライン・タイマーは設定画面から変更できます。絵しりとりの「4箇所中3箇所成立」は仮の基準です。

## まずPCで確認する

ファイルをすべて同じフォルダに置き、`index.html` をブラウザで開くと進行画面を確認できます。ただし、Webアプリとしてのホーム画面登録・オフラインキャッシュは HTTPS 上の GitHub Pages からの利用を想定しています。

## GitHub Pagesへの公開

1. GitHubにサインインし、新規の**公開（Public）リポジトリ**を1つ作ります（例：`family-spy-game`）。
2. ZIPを展開して、**中のファイルを全部**リポジトリのルートにアップロードします。ZIPそのものをそのままアップロードするのではなく、`index.html`、`app.js`、`style.css`、`sw.js`、画像などの各ファイルを配置してください。
3. リポジトリの `Settings` → `Pages` → `Build and deployment` を開き、`Source` を `Deploy from a branch` にします。
4. `main` と `/(root)` を選んで `Save`。
5. 表示されたGitHub Pages URLをiPadのSafariで開きます。URLの例：`https://ユーザー名.github.io/family-spy-game/`（これは例であり、実際のURLではありません）。
6. Safariの共有メニューから「ホーム画面に追加」。表示される場合は「Webアプリとして開く」をオンにして追加します。
7. オンラインで一度起動・読み込みを完了させ、その後Wi-Fiを切って**オフライン動作確認**します。事前の本番テストを推奨します。

※ GitHub Pagesの公開サイトやリポジトリの内容は原則公開されます。個人情報・参加者の実名を**ソースコードに書いてアップロードしない**でください。プレイヤー名はアプリ内で設定すればその端末の保存領域にのみ保持されます。

## 司会の操作順

- 最初に「設定・ルール」で大人5人の表示名を入力。
- 「色の記憶」：20秒タイマー開始 → 配布・配置 → 15マスをタップ採点 → 保存。
- 「絵しりとり」：抽選 → 5人に順番に30秒タイマー → 5枚を検証 → 保存。
- 「文字数しりとり」：実物カードまたはアプリ抽選 → 共通タイマー開始 → 1人ずつカード条件を指定／表示して、正解・失敗を記録 → 10回で結果確認・保存。
- 「結果・スパイ投票」：各競技結果を確認 → 投票 → 開票 → スパイ発表。

### 紙とアプリの役割分担

- **紙**：絵しりとりの作品、文字数しりとりの言葉の記録。
- **アプリ**：抽選、進行、時間計測、正解数・成功判定、投票結果。
- **カメラ**：色の記憶の正解配置をスマホで1枚撮影する場合に限る（アプリと無関係）。

### 文字数の数え方

例：`かめら` = 3文字、`しょうぼうしゃ` = 7文字。「ゃ」「ゅ」「ょ」「っ」や長音「ー」はそれぞれ1文字。漢字表記の語も**読み仮名**で文字数を数えます。外来語か日本語か判断が割れる語は、司会者が判定してください。失敗後に次の人がどの言葉から続けるかも司会者が決めてください。

## データと技術的な注意

- 画像・回答はサーバーへ送信しません。JavaScript単体で動作し、**外部API・外部CDNは利用しません**。
- 途中の進行・保存した競技結果・投票は `localStorage` に保存。Safariやホーム画面アプリのデータ消去で失われる場合があります。
- 結果のコピー・JSONの書き出しに対応。ブラウザによってファイル保存操作が異なります。
- アプリ内の時計は端末の時刻に基づき、裏に回っていても経過を反映する設計です。iPadのオートロックを一時的に長めにし、消音を解除しておくと使いやすいです。
- Webアプリが更新されないときはオンラインでページを開き直してください。`sw.js` の `CACHE` バージョンを更新すれば新バージョンに切り替わります。
- 第三競技に実物カードを使う場合、同じ数字・色のカードは2枚まで使えます（♥♦または♠♣）。

## ファイルの役割

- `index.html`：起動ページ
- `style.css`：iPad向け画面デザイン
- `app.js`：進行・抽選・タイマー・結果保存
- `manifest.webmanifest` / アイコン：ホーム画面アプリ用
- `sw.js`：オフラインキャッシュ
- `.nojekyll`：GitHub Pages向け
