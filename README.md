# SPY GAME 司会室 v1.3（2026年11月20日更新）

大人5人＋子ども2人の家族スパイゲームのための、iPad向け司会進行アプリです。
**HTML / CSS / JavaScriptだけで構成。外部サービス・外部ライブラリ不要。**

## 更新内容

- 従来の3競技（色の記憶・順手逆手絵しりとり・文字数しばりしりとり）を維持
- **第4競技「数字並びチャレンジ」**を追加。実物のトランプA〜Kから異なる5枚を1枚ずつ配り、自分の数字だけ見て小さい順に並ぶ。直接的な数字・数字を特定する手がかりは禁止。タイマー（初期90秒、設定変更可）と並びの数字入力による自動判定／ワンタップ手動判定を実装
- **第5競技「人間ひらがなクイズ」**を追加。46文字から重複なくランダムに1文字ずつ抽選。特大お題表示・正解＋1・パス・正解数7問目標。タイマーは外部で計測するため、画面内にはなし
- **第6競技「図形で伝えろ！」**を追加。ひらがなの24お題をランダム抽選。子ども2人と補助役の大人1人だけに表示するための「お題を隠す／表示」切り替えあり。○△□と、補助役が別途用意した特別図形から2個選ぶ（2個とも必ず使用）。大人のアドバイスOK、並べるのは子どもだけ。大人4人が答える。5問中3問正解は**仮の基準**。パスは1問消費
- ホーム、競技履歴、結果一覧、スパイ投票を6競技向けに更新

## GitHub Pagesで既存サイトを更新する

すでに `https://aokazu823-lang.github.io/spygame/` を公開している場合：

1. `spy-game-ipad-final.zip` を**解凍**する
2. GitHubの `https://github.com/aokazu823-lang/spygame` を開く
3. `Add file` → `Upload files` で解凍した**フォルダの中身すべて**をリポジトリのルートにドラッグ（`index.html`、`app.js`、`style.css`、`sw.js`、`manifest.webmanifest`、各アイコンなど）
4. 既存ファイルを更新する内容で `Commit changes`。アップロードするファイルはZIP自体ではない
5. `Actions` → Pages のデプロイが成功したら公開URLにアクセス
6. iPadではSafariからオンラインでサイトを開き直し、更新されたメニューを確認する。ホーム画面アプリが旧版のままなら、サイトの再読み込み・一度閉じて再起動を試す

公開したサイトのソースコードは第三者が閲覧できます。**本名などの個人情報をコードに書き込んでアップロードしない**でください。アプリの設定画面で入力した名前はその端末の保存領域にのみ保持されます。

## 当日の操作の要点

- **色の記憶**：子ども2人がA3台紙に色カード15枚で問題を作り、**別のカメラで正解写真を1回だけ撮影**。20秒暗記→大人5人にランダムで3枚ずつ配る→表向きに順番で配置→15枚中12枚以上なら成功。追加の写真撮影は不要
- **順手・逆手 絵しりとり**：大人5人の順番と、順手3人・逆手2人を抽選。絵を紙に残し、4か所のつながりを採点。4か所中3か所成立は仮基準
- **文字数しばりしりとり**：赤=カタカナ語、黒=それ以外。2〜6の数字が文字数。全員相談禁止、大人5人×2巡=10手番、全員共通5分（設定可）。回答は紙に書いてから発表
- **数字並び**：実物のカードを配る。数字を直接言ったり「偶数」「一桁」などを示したりしない。全員が並んだらカード公開、iPadで数字入力または成功／失敗の記録
- **人間ひらがな**：子ども2人が床で文字の形を表現し、黒子の大人1人が安全に補助。残る大人4人が回答。子どもを持ち上げない。外部タイマーで5分、7問正解を目指す。iPadはお題と正解数だけ
- **図形で伝えろ！**：お題は24候補。補助役の大人1人だけが特別図形を2個選び、子ども2人が**必ず両方**を使う。○△□は自由。補助役の口頭アドバイス可、配置は子どものみ。回答者4人にお題を見せずに進行。5問中3問正解は仮基準

## 運用上の注意

- `localStorage` に端末内データを保存。**前のv1/v1.1で入力した名前・保存済み結果も引き継ぐ**ようにしてある（同じiPad、同じサイトの保存領域の場合）
- 保存領域の削除、端末の変更、ブラウザとホーム画面アプリの切り替えで記録が共有されない場合がある
- ネット接続があるときに一度開いてから、念のため事前に機内モードで起動確認する
- 家族用の司会補助ツール。時間切れ・曖昧な回答は司会者が判定する
- 4ヒント連想ゲーム・AI画像曲当てクイズ・紙コップゲームは今回入れていない
